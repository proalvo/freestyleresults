# FreestyleResults
Results software for the canoe freestyle competitions.

Coming soon: Totally new version of the FreestyleResults software for Windows 11 and Linux, with option to publish resuls on https://freestyleresults.com. Be in contant if you are intrested to test the software before the first release.  

## Main features'
*Results* – live rankings with ICF/Paddle Worldwide tie-breaks, qualification (Q) and advancing athletes to the next phase.
*Competitions and events* – competitions, events and phases built from ICF or custom progression systems.
*Athletes* – athlete entries, bibs and seeding, with CSV import, with option to integration with registration system.
*Rule sets* – moves, bonuses and progression systems, imported and exported as JSON files.
*Judging* – tablets for up to three judges and the head judge, with scores following each run live.
*Streaming* – overlays for live video, including the run clock from a timing system.
*Printed results* – PDF results with the competition's header and footer banners.
*Website* – results published to the FreestyleResults website as they happen.
